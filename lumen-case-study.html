Lumen Crypto Market Analysis

View Project ↗

Lumen is a cryptocurrency market analysis tool that provides insights into over 100 cryptocurrencies simultaneously. It stores data in its own optimized database, ensuring fast retrieval and seamless access through advanced API calls. Users can search and query the extensive dataset, share currency information with friends, and benefit from a self-hosted platform with an easy and straightforward setup. Lumen is designed for speed, efficiency, and simplicity.

Self-hostable

Clone the Github repo, follow the instructions on the page and your live!

Advanced Database Querying

Search through masses of data stored locally efficiently

Real-Time Financial Data

Data is timestamped so you can verify your data is live.
