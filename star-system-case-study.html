Star System Builder

View Project ↗

Star System Builder generates a scientifically viable habitable star system. There is a range of formulas used to calculate attributes of the system to a high degree of accuracy. In future versions of the program the accuracy should be improved but as it stands it is more than capable of building star systems for a range of purposes like game development, worldbuilding, gaming, storytelling, and fun. The data work is done using python and then flask is used to get that data into HTML format for a clean webpage designed with pure css.
